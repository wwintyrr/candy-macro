# Candy Macro
idk simple GPO candy macro, no venv just install the dependencies

### 1. Clone repository:
```bash
git clone https://github.com/wwintyrr/candy-macro
cd candy-macro
```
### 2. Download dependencies:
```bash
pip install -r requirements.txt
```

then just launch main.py.
for this to work on mac, try adapting the pydirectinput to another library like pyautogui.
